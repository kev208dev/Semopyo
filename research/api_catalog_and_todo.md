# 세모표 데이터 API 카탈로그 & 작업 분담

> 조사일 2026-06-11. 세모표 7개 카테고리(음료·맵기·1인분·신발·옷·가공식품·바코드)에
> 쓸 수 있는 공공 API를 전수 조사하고, **자동으로 처리한 것**과 **사용자가 직접 해야 하는 것**을 분리.

## 1. 한눈에 — 작업 분담

### ✅ 내가(에이전트) 이미 처리한 것
- **식품영양성분DB 전건 282,296건 수집 완료** (data.go.kr 15127578, 1인분/가공식품 영양)
  → `data/food_nutrition.csv`, `data/food_nutrition_master.csv`(1인분 환산 포함)
- **바코드 스캔 → 비교 기능 앱에 구현** (`lib/barcode_scan_page.dart`, `lib/barcode_api.dart`, 홈 진입 버튼)
- **Open Food Facts 폴백 내장** — 키 없이도 일부 제품 조회됨(한국 커버리지는 낮음)
- **식품안전나라 일괄 수집 스크립트 준비 완료** (`scripts/fsk_pull.py`) — 키만 오면 즉시 실행

### 🙋 사용자가 직접 해야 하는 것 (아래 2장 체크리스트)
1. 식품안전나라 인증키 발급 마무리 → 키 전달
2. (선택) data.go.kr 추가 데이터셋 활용신청
3. (선택·유료) GS1 코리안넷 제휴 — 최신 바코드/이미지/치수가 필요할 때만

### 🚫 공개 API가 아예 없는 것 (자체 데이터 구축 필요)
- **음료 용량(카페 사이즈), 맵기(스코빌 SHU), 신발 사이즈, 의류 사이즈**
  → 한국·글로벌 모두 공식 공개 API 없음. 지금처럼 리서치/수기 DB가 유일한 방법.

## 2. 사용자 TODO 체크리스트

### [필수] ① 식품안전나라 인증키 — 발급 마무리
- 포털: 식품안전나라 공공데이터활용 (foodsafetykorea.go.kr, 로그인됨)
- 경로: **공공데이터 검색창에 "유통바코드" → 상세 → "OpenAPI 신청/활용신청"** → 신청하면 인증키 자동 발급
- 발급된 키는 **"인증키 관리 → 인증키 신청 현황"** 에 표시됨
- **이 키 1개로 I2570(바코드)·I0750(품목제조)·I2790(영양) 전부 호출 가능** (서비스별 추가 신청 불필요)
- 👉 키 문자열을 전달 → 내가 `lib/barcode_api.dart` 의 `kFoodSafetyApiKey` 에 넣고 I2570·I0750 전건 수집

### [선택] ② data.go.kr 추가 데이터셋 활용신청
- 필요 시 각 데이터셋 페이지에서 "활용신청"(자동승인) → 같은 data.go.kr 일반 인증키로 사용
  - 바코드연계제품정보 15060549 (품목보고+바코드+식품유형)
  - 건강기능식품 영양DB 15085712 (건기식, 우선순위 낮음)
- ※ ①의 식품안전나라 키로 대부분 대체되므로 급하지 않음

### [선택·유료] ③ GS1 코리안넷 제휴
- 최신 신제품 바코드 + **상품 이미지·규격·치수**까지 필요할 때만
- 무료 아님: 사업성 심사 + 초기 연계비·월 사용료 협상 (문의 02-6050-1483)
- 무료 API(I2570 등)는 2018년 이후 갱신 중단이라, 최신 커버리지의 근본 해결책은 여기뿐

## 4. 카테고리별 데이터 소스 결론

- **1인분 / 가공식품 영양** → ✅ 식약처 영양DB (수집완료) + I2790/I0750(키 오면 보강)
- **바코드 → 제품** → I2570 + 바코드연계(무료, 2018한계) → 최신은 GS1(유료) / OFF(폴백)
- **음료 용량 · 맵기 · 신발 · 의류** → 공개 API 없음. 자체 리서치/수기 DB 유지가 정답
